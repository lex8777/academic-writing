# Claim–evidence checklist

| Claim type | Required evidence |
|---|---|
| Higher CO2 uptake | TG or breakthrough data with clear normalization |
| Faster carbonation kinetics | Time-resolved TG, kinetic fitting, or in situ tracking |
| Liquid molten-salt phase | DSC, phase diagram, in situ XRD disappearance, or literature phase data |
| Intermediate carbonate formation | XRD, Raman, FTIR/DRIFTS, thermodynamic calculation, or complementary phase analysis |
| Defect-rich MgO | XRD peak broadening, XPS shifts, TEM, Raman, or defect-sensitive evidence |
| Better cyclic stability | Multi-cycle TG data and post-cycling structural characterization |
| Sustainability relevance | Regeneration temperature, energy penalty, material abundance, process compatibility, or comparison with existing capture routes |

If evidence is indirect, use cautious language.
If evidence is absent, flag the sentence instead of strengthening the claim.
